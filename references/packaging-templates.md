# 成果封装模板（Packaging Templates）

把萃取出的"打法"封装成可传播、可训练、可验证的成果物。核心是成果7步法：
**主题包装 → 内容建模 → 口诀编撰 → 工具打磨 → 公式建立 → 话术书写 → 形成案例**。

> **v2.0 配合使用**：本文件负责"单条打法/单个成果"的封装形式；**组织级项目建议直接用 `skill-pack-template.md` 把整套成果打包成"可安装团队技能包"**（打法库 + 成果物 + 训练包 + 验证包 + DIGEST），本文件的成果形式库是技能包内各单元的选择器。封装前对每条打法过三重验证门禁（`verification-gates.md`）。

## 成果形式库（先定形式，再套模板）

一次萃取先别急着写文档。**先按"三问"定成果形式，再按下方模板封装**——同一份打法，可以按用途产出完全不同形态的成果。

### 三问选择器：给谁看 × 要达成什么 × 发在哪

| 三问 | 选项 | 锁定什么 |
| --- | --- | --- |
| ① 给谁看 | 自己 / 团队 / 陌生粉丝 / 付费学员 | 深度与措辞 |
| ② 达成什么 | 记住 / 学会 / 传播 / 变现 | 成果类型 |
| ③ 发在哪 | 文档 / PPT / 小红书 / 短视频 / 朋友圈 / 培训现场 | 形态与载体 |

**口诀：先问三件事，再选一种形。** 三问答完，从下表锁 1~2 种最优形式（默认给"沉淀型 + 一种传播/工具型"双成果）。

### 六大用途 × 具体形式

| 用途 | 成果形式 | 适用场景与要点 |
| --- | --- | --- |
| ① 沉淀留存 | 个人经验手册 · 方法论模型图 · 一页纸/一纸禅 · 知识卡片组 · 思维导图 · 复盘行动卡 | 给"自己/团队"长期复用；要点是结构化+可回溯 |
| ② 传播涨粉 | 公众号文章 · 小红书图文 · 金句九宫格 · 短视频口播脚本 · 朋友圈卡片 · 海报 | 给"陌生粉丝"，要点是金句化+有钩子+画面感 |
| ③ 教学带教 | 培训课程大纲 · PPT课件 · 演练剧本 · 带教陪跑计划 · 试题考核表 · 讲师讲稿 | 给"学员/新人"，要点是分步+演练+可考核 |
| ④ 工具即用 | 模板清单 · 话术库 · 检查单 · SOP卡 · AI助手Prompt · 打分表 · 决策清单 | 给"直接上手"，要点是即插即用、少废话 |
| ⑤ 变现产品 | 付费内容 · 课程大纲 · 电子书 · 咨询产品包 · 训练营方案 | 给"付费用户"，要点是价值显性+交付明确 |
| ⑥ 组织复制 | 标准动作库 · 案例库 · 岗位经验地图 · 知识库条目 · 新人上岗包 | 给"组织规模化"，要点是统一口径+可验证 |

**每种形式的具体模板见下文"成果类型与模板"（1~8 为通用内核，可按用途组合套用）。** 例如：传播型 = 一句话SOP + 金句卡 + 案例库；教学型 = 方法论框架 + 步骤清单 + 培训课程。

## 成果类型与模板

### 1. 一句话SOP（最常用）
用固定句式把经验压成一句话，方便记忆与传播：
> **如果**（情境）…**切忌**（常见错误）…**那么就**（正确做法）…**避开**（陷阱）…**从而**（结果）…

示例（客户跟进）：如果客户说"再考虑考虑"，切忌立刻降价或追问，那么就预约具体时间再跟进并留下钩子，避开被拖入无限期拖延，从而推进成交节奏。

### 2. 步骤清单（SOP / 标准动作）
把关键行为拆成有序步骤，每步含：动作 + 要点 + 反例。
| 步骤 | 关键动作 | 要点/技巧 | 常见错误 |
| --- | --- | --- | --- |
| 1 | ... | ... | ... |

### 3. 方法论框架（模型图）
- 把散点经验归纳成结构化模型（如"三高模型""四环七步"）。
- 命名要易记：用数字+关键词（如124N1、SBP、STAR）。
- 画成图时：流程类用步骤流，结构类用分层/分组。

### 4. 口诀/公式
- 把要点压缩成朗朗上口的口诀（如"一定二顺三发现"）。
- 公式：把变量与结果的关系显性化（如"转化 = 信任 × 价值 - 阻力"）。

### 5. 案例库（STAR 案例）
每个案例需四要素 + 附加项：
- 情境（S）、任务（T）、行动（A）、结果（R）
- **有数据**：量化结果；
- **有对标**：和谁比、好多少；
- **有金句**：一句可传播的总结；
- **有画面**：细节让读者能"看见"。

### 6. 工具/模板包
- 可复用的表格、话术脚本、检查清单、开场白/收尾语模板。
- 如：客户需求挖掘清单、跟进话术脚本、复盘五问卡。

### 7. 培训课程/训练方案
- 学习目标（业务目标+行为指标+规则）。
- 课程结构：集中学习 + 微行动学习 + 每周死磕一个行为。
- 演练剧本四部分：场景设定、角色扮演、标准话术、反馈点评。

### 8. 一纸禅（极简封装）
把一条经验压到一页/一句话，适合快速沉淀与传播：
- **一事**：发生了什么事？
- **一得**：有哪些经验总结？
- **一问**：如何举一反三？
> 搭配"一句话SOP"使用：如果…切忌…那么就…避开…从而…。完整战法见 `method-library.md`。

## 完整输出骨架（个人经验手册 / 组织经验包）

```
主题：XXX（做什么）
├─ 一句话结论（口诀/SOP）
├─ 核心方法论（模型/框架）
├─ 分场景做法（步骤清单）
│   ├─ 场景A：步骤+要点
│   ├─ 场景B：步骤+要点
│   └─ ...
├─ 典型案例（STAR，含数据/对标/金句）
├─ 关键工具（模板/清单/话术）
├─ 适用边界（适合谁/不适合谁/何时失效）
└─ 训练与验证建议（如何练/如何验证）
```

## 输出规范

- **保留原始语言**：金句用受访者原话，不擅自改写。
- **命名易记**：方法命名用"数字+关键词"结构，方便记忆与搜索。
- **可验证**：每个成果都要能回答"怎么知道它有效"（指标/数据）。
- **控制篇幅**：按用户偏好输出，默认给结构化清单+可视化（流程图/模型图）。
- **注明来源与边界**：标出萃取对象、场景、适用条件，不夸大普适性。

## 成果结构化四要素（陈晓燕）
1. 任务背景、难点冲突点；
2. 结论先行：模型口诀；
3. 过程分解：步骤话术；
4. 附件：工具、模板。
（"有过程、有成果、可追溯、可视化"——每份成果都要能回答"怎么来的、给谁用"。）

## 经验建模四步（叶敬秋）
要点提炼 → 规律提炼 → 模型提炼：把散点做法压成"步骤+要点+难点对策"，最后画成逻辑关系图/模型（如流程图、结构图）。

## 知识结构化提炼的常用逻辑（叶敬秋）
- **结构型逻辑**（主体维度）：按组成模块分。
- **流程型逻辑**（主体维度）：按时间/步骤分。
- **Why-What-How 型逻辑**（细节维度）：按"为什么-是什么-怎么做"分。
- **问题型逻辑**（细节维度）：按"问题-对策"分。
