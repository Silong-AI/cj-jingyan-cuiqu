# 入口分流与场景诊断（Entry Routing）—— CJ·经验萃取 v2.0

把"我要萃经验"这句模糊需求，**30 秒内分流到正确的路径**，并对模糊需求做反向诊断。避免一上来就按默认流程硬跑，导致方向跑偏或成本失控。

## 一、入口分流（第一步必做）

收到用户说"萃经验 / 做经验萃取 / 复制高手"后，先判断属于哪条路径：

| 用户输入 | 路径 | 落点 |
| --- | --- | --- |
| 明确要萃某个人（专家/销冠/老员工/自己） | **个人模式** | `mode-individual.md` |
| 明确要给企业/团队做组织级复制 | **组织模式** | `mode-organization.md` |
| 多位高手一起共创（工作坊/共创会） | **团队共创** | `mode-organization.md` 的"专家经验共创画布" |
| 想萃自己（个人经验沉淀） | **个人模式·萃自己** | `mode-individual.md` + 自我认知偏差提示 |
| 只有模糊需求（"想让团队更会卖货"） | **场景诊断**（见下节） | 反推后回对应路径 |
| 只有一段素材/录音/笔记，没有明确对象 | **素材萃取** | `ai-assist.md` + 批量聚类 |

> **分流不阻塞交付**：能直接推进就给默认路径先推进；用户回答只影响方向调整，不要把价值卡在提问后面。

## 二、场景诊断（模糊需求 → 反推萃取设计）

用户说不清"萃什么、萃谁"时，通过 1~2 个追问定位，然后反推出完整的萃取设计。

### Step 1：定位业务问题（最多 2 轮追问）
| 需求表述 | 典型萃取主题方向 |
| --- | --- |
| "团队业绩上不去 / 转化率低" | 高价值业务场景（新客开发/成交/续约） |
| "新员工上手慢，老带新靠运气" | 岗位经验地图 / 新人上岗包 |
| "同样的事，有人做得好有人做不好" | 关键行为差异萃取（牛招识别） |
| "组织里经验都散在个人手里" | 组织级经验复制项目 |
| "复盘做了但没沉淀出东西" | 复盘+萃取战法（盘后即萃） |

### Step 2：反推萃取五要素（诊断结果）
```
萃取主题：锁定具体场景（从业务痛点 / 高光事件 / 卡脖子难题来）
萃取对象：谁做得好？（三高模型筛选）
给谁用：新手 / 团队 / 全员？（决定详略）
产出形式：SOP / 课程 / 案例库 / 技能包？（三问选择器）
验证方式：用什么指标证明有效？
```

### Step 3：直接给推荐方案
给出"萃什么 → 萃谁 → 产出什么 → 怎么验证"的一页方案，让用户确认或调整，不要问一堆开放问题。

## 三、档位管理（控制成本与深度）

开跑前先确认档位，避免长访谈成本失控（对标 nuwa 的成本透明）：

| 档位 | 访谈/共创规模 | 适用场景 | 深度 |
| --- | --- | --- | --- |
| **快速** | 1 位高手 · 30-45 分钟 · 挖 1 个主题 | 先试试效果 / 预算敏感 | 挖到"方法+牛招"层 |
| **标准（默认）** | 1-2 位高手 · 2 轮深挖 · 挖透 1 个场景 | 大多数场景 | 挖到"心法+边界"层 |
| **深度** | 多位高手 + 共创 + 批量聚类 | 组织级项目 / 出标准动作库 | 全流程 + 冲突仲裁 + 技能包 |

> 用户说"就做一下"没更多信息 → 默认标准档 + 个人/组织看场景，直接推进，别反复问。

## 四、检查点（防跑偏的关键）

在以下节点**必须暂停展示中间产物，让用户确认后再继续**（对标 nuwa 的 Checkpoint，防止写完全部才发现方向不对）：

| 检查点 | 时机 | 展示什么 |
| --- | --- | --- |
| **① 骨架确认** | 定完场景/对象/产出后 | 萃取设计一页纸：主题/对象/产出/验证 |
| **② 打法清单** | 每轮深挖后 | 已挖出的打法清单（方法/动作/工具/牛招），标出"待补" |
| **③ 验证清单** | 三重验证筛选后 | 通过的 N 条打法 + 淘汰的 M 条及原因 |
| **④ 成果确认** | 封装前 | 成果物形态与结构预览 |

**检查点 ≠ 阻塞**：凡是能给默认值的都给默认值；如果下一步不依赖用户答案，先出产出再让用户调整。

## 五、断点续跑（任何长流程都不重来）

- 每次萃取在成果目录维护一份 `EXTRACTION_STATE.md`：当前阶段、已挖出的打法、待追问点、已确认项。
- 中断或换会话后，先读状态文件，从断点继续，不要从头重来。
- 状态文件结构：
```markdown
# 萃取状态
主题：___
对象：___
档位：___
当前阶段：[定/萃/验/用]
已挖打法：
- [ ] 打法1（已到：方法层）
- [ ] 打法2（待挖：工具层）
待追问点：
- ...
下一步：___
```
