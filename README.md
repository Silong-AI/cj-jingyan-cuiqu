# CJ·经验萃取（Experience Extraction）v4.5.0

> 把「人会做但说不清」的高手经验，变成「看得见、学得会、用得着、验证过」的个人方法论或团队技能包。

通过**对话式动态萃取**完成经验提炼——每轮听完回答给出 2~5 个编号追问方向，由被萃取者自选深挖，问得越多挖得越深。

---

## 这是什么

一个基于 Agent Skills 规范构建的经验萃取 Skill，核心能力：

- **对话式追问**：动态菜单 + 自选方向，对抗认知闭合，把隐性经验挖出来
- **五层深度状态机**：基操 → 方法 → 牛招 → 心法 → 边界，识别「只有他会」的牛招
- **三重验证门禁**：每条打法过跨域复现 / 预测力 / 独特性，不过就降级淘汰
- **产出即落地**：个人萃取产出方法论手册，组织级萃取直接产出可安装团队技能包

**适用场景**
- 个人经验萃取：萃取某个人（专家/销冠/老员工/自己）在特定领域的成功打法
- 组织级经验复制：锁定关键业务场景，从多位高手批量萃取 → 标准动作库/培训课程/团队技能包

---

## 快速开始

启用本 skill 后，直接说：

```
帮我萃一下我们销冠的成功经验
想把老王做单子那套方法整理出来
团队新人上手太慢，怎么办
```

Skill 会按 **定 → 萃 → 验 → 用** 四阶段推进：

1. **定**：入口分流 → 定场景/人/对象 + 档位（快速/标准/深度）
2. **萃**：五层状态机 + 追问菜单，动态深挖直到区分出基操与牛招
3. **验**：三重验证门禁，每条打法过验证才进入成果
4. **用**：按使用场景封装成果物（手册/课程/工具包/技能包/变现产品）

完整流程见 `SKILL.md`，详细方法论在 `references/`。
