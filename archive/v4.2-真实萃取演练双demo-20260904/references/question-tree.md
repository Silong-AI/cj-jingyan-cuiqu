# 追问决策树（Question Tree）—— 对话式动态萃取

把访谈从"背问题清单"升级为"动态对话"：**每听完一段回答，先判断它属于哪种类型，再给出 2~5 个可选的追问方向（编号菜单），由被萃取者自选**。选得越多挖得越多，拿到的经验越完整。

> **v2.0 配合使用**：本文件负责"每轮问什么方向"（八大追问方向菜单）；执行时请同时用 `extraction-state-machine.md` 判断回答层级（基操/方法/牛招/心法/边界）、识别牛招、按判停条件收敛，并维护 `EXTRACTION_STATE.md` 支持断点续跑。两者咬合才是完整的 v2 动态萃取。

## 一、为什么必须动态追问

- **认知闭合本能**（叶敬秋）：人面对模糊信息急于下结论，越急着总结，越容易跳过关键细节、只给表面答案。萃取师要：**识别本能 → 抵制敷衍 → 拉长思考 → 深挖隐性**。对急着给答案的人往回拉，让其回到真实场景的具体动作里。
- **问得越多，经验越厚**：经验藏在细节里。一个"挑战"往往由多个小挑战组成，一个"做法"由多个动作组成。每多追问一层，可复制的部分就多一层。
- **基操 vs 牛招**：追问的目标是区分"谁都会的基操"和"只有他会的牛招"，牛招才是值得封装的部分。
- **知识的诅咒**（刘永中）：高手太熟悉自己的做法，反而不觉得哪里关键。萃取师要"假设自己完全不懂"，用外行的角度逐层往下问。

## 二、对话导航总览

```
被萃取者回答一段话
   │
   ├─ 判断回答类型（见第三节）
   │
   ├─ 从"八大追问方向"里挑出当前最相关的 2~5 个，编号成菜单
   │
   ├─ 请被萃取者自选一个（或提示"想挖得深建议选 X"）
   │
   └─ 按所选方向追问 → 得到新信息 → 回到顶部，重新出菜单
       循环，直到该主题挖透（区分出基操与牛招、拿到可复制动作）
```

- 一轮对话只围绕"一个主题 + 一个方向"，宁深勿广。
- 当回答含糊、空泛、像观点不像事实时，**不允许直接跳到下一个主题**，必须先从菜单里强制选择一个方向深挖。
- 对话结束时用"一句话总结"收敛（见第八节收尾）。

## 三、判断回答类型（30秒内完成）

| 对方回答像… | 说明 | 应优先给的方向 |
| --- | --- | --- |
| 观点/结论（"关键是要坚持"） | 缺事实，最需要挖 | 拆解 / 还原场景 / 挖动作 |
| 大而全（"我做了很多事"） | 没边界，太泛 | 拆解 / 挖对标 |
| 具体做法 | 有料，往下钻 | 挖动作 / 挖工具 / 挖验证 |
| 成功结果 | 别满足，挖过程 | 挖动作 / 挖反例 / 挖对标 |
| 失败/踩坑 | 金矿，别跳过 | 挖边界 / 挖验证 / 挖金句 |
| 心法/理念 | 升维但易空 | 还原场景 / 挖工具 / 挖验证 |
| 抱怨环境（"当时资源太差"） | 藏做法 | 挖动作 / 还原场景 |

## 四、八大追问方向（菜单来源）

### ① 拆解 Challenge Splitting
**适用**：对方给的是大主题/大挑战/笼统答案。
- "你说的『最大的挑战』，具体是指哪几件事？"
- "如果把这件事拆成 3 个小关，最要命的是哪一关？"
- "这里面哪一部分是你自己可控的，哪一部分不可控？"
- 工具：鱼骨图（从结果倒推根因）、从业务场景到痛点漏斗（对象→任务→场景→主题）。

### ② 还原场景 Scene Recall
**适用**：需要把对方拉回当时的情境，避免空谈。
- "这件事发生在什么时候？当时你/团队/平台的状态是什么样？"
- "做成之前，你面临的最大处境或难题是什么？"
- "最开始是什么让你觉得这件事有可能做成？"
- 工具：三段式故事框架（起因→过程→结局）、STAR 的 S/T。

### ③ 挖动作 Action Mining
**适用**：对方讲了大概做法，要压到"动作"级。
- "你做的第一个关键动作是什么？"
- "每一步具体怎么做？说给我听，越具体越好。"
- "那个关键时刻，你具体先动了哪一步、后动了哪一步？"
- "能不能再细一点：那个动作你当时是怎么下手的？"
- 工具：STAR 的 A、四挖之"动作"、亮点法"提炼具体行为而非抽象评价"。

### ④ 挖工具 Tool Mining
**适用**：做法清楚了，挖可复制、可交付的载体。
- "你手上有哪些工具、模板、清单、表格、话术？"
- "有没有现成的东西可以直接给别人用？"
- "你开头那句话是怎么说的？能不能还原一句原话？"
- 工具：四挖之"工具/话术"、成果物意识（SOP/口诀/模板）。

### ⑤ 挖验证 Evidence Check
**适用**：对方讲了方法，必须验证"真的有效"。
- "结果怎么衡量？有没有数字？（金额/数量/时间/转化率）"
- "和以往、和别人比，好在哪里？有没有对标？"
- "你怎么知道是这个动作起的作用，而不是别的原因？"
- "如果让一个新人照着做，你觉得他能做到几成？卡在哪？"
- 工具：STAR 的 R、80%目标（让普通人达到60分）、效果/失效条件。

### ⑥ 挖边界 Boundary Probe
**适用**：防止教条，划定适用条件。
- "有没有一次你这样做反而失败了？当时的区别在哪？"
- "这套方法适合什么人、不适合什么人？新手适用吗？"
- "如果市场/客户变了，哪个环节需要调整？"
- "这招在什么情况下会失灵？"（灵魂三问·边界点）
- 工具：探询边界、灵魂三问。

### ⑦ 挖对标 Benchmark Compare
**适用**：找出差异化，提炼"独有的牛招"。
- "你和别人/别的团队做法的最大区别是什么？"（灵魂三问·差异点）
- "同样做这件事，为什么是你做成了，别人没做成？"
- "别人踩的坑，你用什么方式绕开了？"
- 工具：灵魂三问·差异点、淘宝原则（看似相同中找不同、推翻路径依赖）、瑞幸vs星巴克式对比。

### ⑧ 挖迁移 Transfer
**适用**：检验经验的通用性，扩大复用价值。
- "这招除了用在这个场景，还能用在哪些地方？"（灵魂三问·迁移点）
- "如果换一个行业/团队，你觉得哪部分还能直接用？"
- "这里面最通用的那条原则是什么？"
- 工具：灵魂三问·迁移点、内萃外取（向外借鉴、向内沉淀）。

## 五、灵魂三问（褚冬彪，鱼骨图极速萃取法）

挑出对方最得意/最危险的一个做法，连问三句，直击本质：
1. **差异点**：你和别人最大区别是什么？（挖本质）
2. **边界点**：笨蛋照着做会在哪里死？（挖边界/避坑）
3. **迁移点**：这招能用在其他地方吗？（挖算法/规律）

## 六、四问深挖（陈晓燕：识别难点→挖掘做法→反思意图→探询可能）

- **识别难点 4 问**：这个事难在哪？为什么难？别人卡在哪？你当初卡在哪？
- **挖掘做法 4 挖**：方法（怎么拆步骤）→ 动作（每步怎么做）→ 工具（用了什么）→ 窍门（外人不知道的小技巧）。
- **反思意图 3 思**：动机（为什么这么做）→ 依据（凭什么判断）→ 效果（什么条件下有效、何时失效）。
- **探询可能 5 疑**：可行性、边界、变通、反例、可教性。

## 七、追问话术速查表（扩展版）

| 对方表现 | 追问话术 |
| --- | --- |
| 给观点 | "能给我举个具体的例子吗？" |
| 讲得太笼统 | "具体到动作，你第一步是怎么做的？" |
| 讲得太快 | "这块我特别想学，能再慢一点讲一遍吗？" |
| 讲成功 | "有没有失败的案例？区别在哪？" |
| 讲方法 | "这个方法适合所有人吗？边界在哪？" |
| 讲自己 | "别人和你的做法，最大区别是什么？" |
| 讲结果 | "这个结果是怎么一步步出来的？" |
| 讲得太多 | "这里面最关键的一个动作是什么？" |
| 讲得太顺 | "哪个环节是最容易翻车的？" |
| 讲完 | "如果只用一句话教新人，你会说什么？" |

## 八、收尾：一句话SOP 收敛

对话挖透后，用公式让被萃取者自己填完整：
> **如果**（情境）…**切忌**（反例/死法）…**那么就**（核心动作）…**避开**（坑）…**从而**（结果）…

再补三问收口：
- "给你的方法起个名字，叫什么好？"（方便记忆传播）
- "最难教会别人的是哪一步？"（找到教学重点）
- "还有没有你特别想讲、但刚才没提到的？"（兜底遗漏）

## 九、完整对话示范（社群冷启动）

> **萃取师**：我们先聊「怎么把一个社群做起来」。你做过最成功的一个社群，当时最大的挑战是什么？
>
> **高手**：最大的挑战是冷启动——前 100 个用户怎么来。
>
> **萃取师**：这个点能挖得很深。你想先往哪个方向？（用户自选）
> ① 拆解：冷启动具体卡在哪几个环节？
> ② 还原场景：当时你的资源、人手、平台处境是什么？
> ③ 挖动作：你为拉进第一个 100 人，具体做了哪几件事？第一件是什么？
> ④ 挖对标：别人的冷启动和你的做法，最大区别在哪？
>
> **高手**：选③，先说第一件事吧。
>
> **萃取师**：好——你为拉第一个 100 人做的第一件事是什么？
>
> **高手**：我没有广撒网，而是先锁定了 5 个"种子用户"，都是愿意陪我一起建群的人。
>
> **萃取师**：为什么是"陪建群"而不是"来捧场"？这里面的差别是什么？
>
> **高手**：捧场是被动的，陪建是主动的。种子用户要把自己当成"联创"而不是"粉丝"。
>
> **萃取师**：这个想法很关键。我想顺着再挖一层：
> ① 挖工具：你当时用什么话术/方式，让对方愿意当"联创"而不是"粉丝"？
> ② 挖动作：5 个种子选出来后，你下一步具体做了什么？
> ③ 挖验证：你怎么判断"陪建"比"捧场"真的更有效？
> ④ 挖边界：这一招在什么情况下会失灵？
>
> ……（循环往复，直到该主题挖透）

## 十、对话纪律

- **一次只给一个菜单**（2~5 个方向），不要一次抛十几个问题。
- **宁深勿广**：选定一个方向就挖到底，再换方向；不要每个方向浅尝辄止。
- **保留原话与金句**：对方说出的关键动作、原话、数字要原样记录，封装时再加工。
- **对方急着总结时**：主动往回拉，"先别急着下结论，我们回到当时那个动作上……"。
- **区分基操与牛招**：每挖到一个做法，心里标一下"这是谁都会的基操，还是只有他会的牛招"，牛招继续深挖。
- **允许用户跳菜单**：若对方说"这个我不想展开"，尊重并换方向，不要强迫；但可提示"这块往往藏着最值钱的经验，确定不挖吗？"
