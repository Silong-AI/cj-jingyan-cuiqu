# 萃取案例 Demo：B2B 销冠「新客开发」经验 → 团队技能包

> **说明**：本案例为**演示用途的高保真示例**（人物与数据均为化名/示例，非真实访谈记录），目的是完整展示 CJ·经验萃取 v4.0 的**全流程落地方式**：入口分流 → 定向 → 萃（状态机+追问决策树）→ 验（三重验证）→ 用（可安装团队技能包 + 生态对齐）。真实使用时按此结构替换为真实访谈内容即可。

> **开箱即看**：这是本 skill 的「高保真示例」——不看源码，只读这份 README + `01-萃取过程记录.md` + `打法库/` 三张打法卡，就能看到 CJ 从「一次销冠访谈」到「一个可训练团队技能包」的完整产出长什么样。结构可跑：`scripts/validate_skill_pack.py` 一键校验本目录。

## 案例背景

| 项 | 内容 |
| --- | --- |
| 组织 | 某 B2B 软件销售团队（20 名销售） |
| 场景 | **新客开发**（从陌生线索到首次成交） |
| 萃取对象 | 老周（化名）：连续 18 个月业绩前三的销冠 |
| 业务问题 | 销冠做单很牛，但团队其他人学不会，新客转化率只有销冠的 1/3 |
| 萃取目标 | 把老周的新客开发打法，变成全团队可训练、可验证的**技能包** |
| 档位 | 标准（2 轮深访 + 1 次共创） |

## 一句话成果

**老周新客开发的三板斧**：第一通电话不推销（帮忙法）→ 需求探针三问挖真需求 → 种子客户陪建转介绍。配套团队训练法"每周死磕一个行为"。
