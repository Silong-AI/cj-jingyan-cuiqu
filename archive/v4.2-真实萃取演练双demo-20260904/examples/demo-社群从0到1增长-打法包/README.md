# 社群从 0→1 增长打法包

> 把"做社群从 0 到高质量增长"的隐性经验，变成可复制、可训练、可验证的打法包。
> 萃取对象：青影星球AI 社群发起人（一手做过 AI 社群 0→1000+ 人，800 天日报零断更）
> 萃取工具：CJ·经验萃取 v4.1
> 适用：AI 社群 / 养生社群 / 疗愈社群 / 任何主题型知识社群（跨领域可迁移）

## 给谁用

- 想从 0 开始做一个社群的人
- 社群做了一段时间但增长卡住的人
- 想把社群经验分享给别人、做培训的人

## 解决什么

- 0→1 冷启动：第一批种子用户怎么来？
- 内容引擎：社群靠什么持续活跃？
- 1→10 增长：从几十人到上千人，关键渠道是什么？
- 跨领域迁移：这套打法换到养生/疗愈社群还能用吗？

## 打法清单（3 牛招 + 3 方法 + 1 心法 + 2 边界）

| 层级 | 打法 | 一句话 |
| --- | --- | --- |
| 🥇牛招 | 朋友圈递进式冷启动三连发 | 无数字破冰→加数字社会证明→加数字+紧迫感，评论区设筛选标准 |
| 🥇牛招 | 聚合式日报五模块 | 一次发一天聚合内容，五模块结构，转载钩子带来被动增长 |
| 🥇牛招 | 嘉宾场景高信任导流 | 做嘉宾分享时主动放二维码/微信号，高信任场景一次带二三十人 |
| 🥈方法 | 多渠道持续拉新 | 朋友圈/主动邀请/合作伙伴/公众号专门群/视频号/帮忙带 |
| 🥈方法 | 朋友圈持续发社群好评+积极结果 | 每周 1 次，留存+社会证明 |
| 🥈方法 | 高质量内容持续输出 | 跨领域普适，社群必备 |
| 🧠心法 | "为自己"启动心态 | 顺其自然、不强求、精准筛选 |
| ⚠️边界 | 聚合日报未必每个社群都合适 | AI 更新快所以成立；养生/疗愈要看目标 |
| ⚠️边界 | 变现被动、生态合作未起 | 当前短板，需补 |

## 怎么开始（3 步）

1. **读打法卡**：从 `打法库/` 里挑你最需要的一张（建议从「朋友圈递进式冷启动三连发」开始）
2. **照着做**：每张卡有可执行步骤 + 可直接复制的话术
3. **验证**：用卡上的"验证"指标看有没有效，无效就回炉调整
