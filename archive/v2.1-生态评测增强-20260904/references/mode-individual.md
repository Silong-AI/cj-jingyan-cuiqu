# 个人经验萃取模式（Individual Mode）

适用：萃取某个人（专家、销冠、老员工、甚至用户自己）在特定领域做成事的经验，产出个人方法论、经验手册、访谈整理。

> **v2.0 配合使用**：进入本模式前先做入口分流与档位确认（`entry-routing.md`）；访谈执行用 `question-tree.md` + `extraction-state-machine.md`（状态机/牛招判据/判停/断点续跑）；封装前对每条干法过三重验证门禁（`verification-gates.md`）。

## 流程

### 1. 明确萃取主题
- 问清：这个人在哪个领域/场景做得特别出色？（如销售、项目管理、减肥、带团队）
- 确认：产出给谁用？解决什么问题？（决定详略与表达方式）

### 2. 还原真实经历（讲故事）
用 STAR 引导对方讲出具体成功案例：
- **S 情境**：当时面临什么情况/背景？
- **T 任务**：你的目标/要解决的问题是什么？
- **A 行动**：你具体做了什么？（重点，反复追问细节）
- **R 结果**：结果如何？有无数据？（有数字、有对标、有对比更佳）

每讲一个案例，追问提炼：
- **对标**：和别人/和以往比，好在哪？
- **金句**：如果一句话总结这条经验，怎么说？

### 3. 深挖"干法"（关键）
对每个成功行动逐层追问，挖出可复制的方法：
- **做法**：你具体用了什么方法/步骤？
- **动作**：每一步具体怎么做的？手上有哪些动作？
- **工具**：用了什么工具、模板、清单、话术？
- **窍门**：有什么外人不知道的小窍门/诀窍？

### 4. 反思意图（提炼原则）
- **动机**：当时为什么这么做？（背后的判断逻辑）
- **依据**：支撑你这么做的依据/经验是什么？
- **效果**：这个做法在什么条件下有效？什么情况下会失效？

### 5. 探询边界（防止教条）
- **例外**：有没有这样做反而失败的？区别在哪？
- **适用条件**：这套方法适合谁？不适合谁？

### 6. 封装输出
- 按 `packaging-templates.md` 把"干法"封装成：一句话结论（口诀）+ 步骤清单（SOP）+ 典型案例 + 关键工具。
- 最终形成个人经验手册：主题 → 核心方法论 → 分场景做法 → 案例集 → 工具包。

## 个人模式要点
- 尊重对方语言，保留原始金句；封装时再提炼成模型化表述。
- 一次聚焦一个主题/一个关键场景，宁深勿广。
- 个人经验不等于绝对真理：注明适用条件与边界。
- **动态对话优先**：访谈按 `question-tree.md` 走追问决策树，每轮给 2~5 个追问方向菜单，请对方自选深挖方向；常用话术从 `interview-question-bank.md` 取。

## 个人萃取破冰与升维（叶敬秋）
- **改变人生的话题五分类**：原生家庭 / 学生时代 / 工作经历 / 创业经历 / 情感经历——用"你最骄傲的一件事/做得最牛的一件事"切入，帮对方进入高光时刻。
- **话题升维萃取主题**：把具体经历升维成方法论主题（如"在北京买了房子"→"如何在心仪城市成功购房"；"从新人到销售冠军"→"如何成为销售冠军"）。
- **三段式故事框架**：起因（主题、角色、背景、冲突）→ 过程（阻碍困难、危机麻烦、细节、进展）→ 结局（行动、效果、结果）。

## 跨领域案例（证明技能通用性）
- 家庭教育经验萃取示例："如何与躺平的孩子重建信任并引导其走出困境"。流程：访谈录音→文字转录→AI辅助萃取→结构化课程资料。四要点：重建安全感→寻找破冰契机→邀请取代要求→重塑自我认知。
- 复盘画布同样适用于个人生活（如孩子用复盘画布设定并复盘学习目标），个人与组织共用一套"盘目标-盘策略-盘问题-盘经验-盘规律"思维。
