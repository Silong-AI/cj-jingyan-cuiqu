# 方法库补全（Method Library）—— 组织级 & 敏捷萃取方法

本文件补齐主文档与各模式中尚未完整展开的方法论，供"定→萃→用"各环节按需调用。来源：AACTP「经验萃取」全景案例大会（叶敬秋 / 刘永中 / 陈晓燕 / 曾子亮 / 褚冬彪 / 周珊）。

## 一、SBP 敏捷萃取法（刘永中）

针对重点事件"即时复盘、即时萃取、即时封装"，实现理性经验与感性经验高效同步传承。三步：

### S 第一步：Select 选高矿（选准典型事件）
典型事件需满足四标准：
- **有挑战**：有难度，不是简单可完成；
- **具体聚焦**：边界清楚、内容明确，避免宽泛模糊（小主题优于大主题）；
- **富有成效**：事件取得成功，有方法可总结；
- **感性喜悦**：有发自内心的成就感、认同感，含感性因素。
> 口诀：选高矿，选得准，定位清晰，萃取方向不会跑偏，不做无用功。

### B 第二步：Build 建框架（理出脉络）
五步框架，按逻辑顺序展开：
1. **回顾过去**（场域营造：时间长廊——把重要时刻写在便利贴上贴到时间轴，命名≤6字、影响8-20字、价值观2-6字，浏览接龙分享）；
2. **分析现在**（识别趋势：如"假设未来流量管道像太平洋一样粗"）；
3. **规划未来**（明确愿景：基于过去优势+行业趋势）；
4. **达成共识**（明晰使命：长期专注什么、为利益攸关者带来什么价值）；
5. **落实行动**（Continue 继续 / Stop 停止 / Start 开始）。
> 口诀：建框架，按逻辑顺序理出脉络，有逻辑、有结构、有场景感，理性与感性兼具。

### P 第三步：Pick 抓要点（ORID 四维度精炼）
萃取不是记流水账，而是抓取最重要的信息，从四个维度深挖：
- **O 信息（Objective）**：有哪些信息、印象最深刻？
- **R 感受（Reflective）**：有哪些感受最强烈？
- **I 启发（Interpretive）**：有哪些最凝练、最深刻的认知？
- **D 行动（Decisional）**：有哪些最要紧的行动？
> 口诀：抓要点，不断精炼，提升价值，避免平庸流水账。

### 配套
- **企业文化 T 型画布**：文化要素（价值观/使命/愿景）× 文字描述 / 形象表达 / 标志性人物事物，用于文化萃取。
- **SCQA 故事萃取**：情景→冲突→疑问→回答（如华为"泥潭越野车"价值观案例）。
- **SBP 适用**：项目结项、战役复盘、重点事件后的快速知识沉淀；"打一仗，萃一次，不是一万小时低水平重复，而是一万次迭代升级。"

## 二、三阶萃取法（褚冬彪）—— 团队经验提现

把培训从"成本中心"变成"价值创造中心"。三大黑洞：**经验孤岛 / 师徒困境 / 场景茧房**。

### 三阶递进
- **Ⅰ 经验拓展**：学经验-萃经验-演经验（小案例激发兴趣→伙伴现身说法直接抄作业→阶段复盘强制分享）。
- **Ⅱ 经验深挖**：学经验-评经验-用经验（标杆学习→世界咖啡式跨组质疑反思、提炼底层规律→标准化复制、持续迭代）。
- **Ⅲ 经验迁移**：学经验-萃原则-创方案（高光时刻→原则提炼→团队共创，把经验变成可执行的解决方案）。

### 4D 绝招提现
- **D1 发现 Discovery**：每个人分享一个独门绝技（2min），选定一个积极场景起标题（1min）；
- **D2 梦想 Dream**：提现场景（把这个绝技放到什么场景最值钱）；
- **D3 设计 Design**：提炼 SOP（用一句话SOP公式把碎片组装起来）；
- **D4 实现 Design/Action**：制定个人一小步行动。

### 鱼骨图极速萃取法
1. **定主题**：在鱼头写具体技能主题（禁止"如何做好销售"这类太泛主题；例"3句话让老板秒批报销单"）；
2. **搭骨架**：4 根主骨（起手·破局动作 / 心法·底层逻辑 / 利器·工具话术 / 排雷·避坑指南），每根下 2-3 个子骨，用关键词不写长句；
3. **点穴位**：灵魂三问——只选 1 根最得意/最危险的主骨，搭档问 3 个问题（差异点：和别人最大区别？边界点：笨蛋做会在哪死？迁移点：这招能用在其他地方吗？）；
4. **萃公式**：一句话 SOP 输出。

### 124N1 流程
1 选题组队→2 群策群力→4 分组实践定期复盘→N 三阶萃取经验变现→1 经验封装项目总结。"没有完美的个人经验，只有不断进化的团队智慧。"
**九大促动技术**（过程引擎）：开放空间、聚焦式会话、群策群力、世界咖啡、复盘萃取、鱼缸会议、团队共创、欣赏式探询、未来探索。

### 721 法则与三大陷阱
**721**（CCL 领导力提升法则）：70% 实践中学 + 20% 互动中学 + 10% 课堂学。
**三大致命陷阱**让 721 变成最昂贵的无用功：
1. 团队只实践、不萃取；
2. 团队学习流于形式，没有标准和深度复盘，学不会、教不好；
3. 随便上几天课，学习与实战脱节，无认知迭代、能力迁移。
> 破解：把"学经验→萃经验→用经验"嵌入每次实践，用训战闭环补上缺失环节。

## 三、训战六步：启萃训演战盘（曾子亮 / 周珊）

训战合一的六步实施流程，以事修人、以人成事：
1. **启**（启动）：选题立项，明确业务收益与目标指标；
2. **萃**（萃取）：高手访谈/共创萃取，形成标准战法；
3. **训**（训练）：集中学习 + 教学设计（TELL/SHOW/DO；授课五环节"备启承展合"；技能养成三要素：逼真场景与挑战 + 高频针对性练习 + 及时有效反馈）；
4. **演**（演练）：实战演练 + 剧本构建（场景设定、角色扮演、标准话术、反馈点评）；
5. **战**（实战）：10 周关键行为死磕计划 + 管理者带教；
6. **盘**（复盘）：GRAI/CSS 复盘，迭代更新。
> 配套"黄埔带兵法七步"：我说你听→我做你看→你做我看→你复盘我看→你做我看你复盘→你做我看你带人→你做我看你带人复盘。

## 四、复盘工具族（陈晓燕 / 曾子亮）

- **结构化四步复盘法**：回顾目标 → 评估策略 → 反思过程 → 总结规律；反思过程四原则：按顺序、是事实、需完整、无观点。
- **GRAI 复盘**：Goal 回顾目标 → Result 评估结果 → Analysis 分析原因（鱼骨图/五个为什么挖真因）→ Insight 总结规律。
- **CSS 复盘**：Check 回顾 → 反思（S）→ 重构（S），用于产出行动计划。
- **复盘画布四大模块**：回顾目标（战略解码）、评估策略（战术支撑）、反思过程（战斗反思）、总结规律（战备系统）。
- **复盘+萃取时机矩阵**（边战边萃·战萃一体·战传合一）：项目初起盘目标/战前研究标杆巧迁移；步及正轨盘策略/验证；项目至中盘问题/经验涌现快速复制；项目中后盘经验/验证；项目结项盘规律/固化打法迭代系统。
- 深挖诊断：目标不清用"上堆战略、下切承诺、寻因结构、问果指标"；亮点用"拍照式学习→解剖式追问→基因式重构"；不足用"反思行为/假设/认知/系统"。

## 五、一纸禅（极简萃取）

一事一得一问，快速压出核心经验：
- **一事**：发生了什么事？（一句话说清事件）
- **一得**：有哪些经验总结？（一条最有价值的收获）
- **一问**：如何举一反三？（换个场景还能怎么用）
> 适用于：日常快速沉淀、社群分享、周报复盘、碎片化经验记录。

## 六、规范萃取六步法（聚焦式）

1. **聚焦主题**：锁定具体萃取主题；
2. **聚焦场景**：明确业务场景与边界；
3. **素材收集**：收集案例、数据、工具；
4. **素材整合**：归纳分类、去伪存真；
5. **案例撰写**：STAR/SCQA 结构化成文；
6. **教学设计**：转为可传授的课程/训练内容。

## 七、IFD 行为分类标准（曾子亮，销售场景）

按三维度给关键行为分类，决定萃取优先级：
- **I Important 重要**：影响成败的关键行为；
- **F Frequent 高频**：反复出现的行为；
- **D Difficult 困难**：新手难以掌握的行为。
> 三维度都高的行为优先萃取。可用于任何岗位的关键行为筛选（与"重要度×频率×难度"筛选矩阵同源）。

## 八、组织经验萃取五阶段（通用）

确定对象 → 明确问题 → 分析个案 → 整合内容 → 导出成果（每阶段配实用工具，如 STAR、鱼骨图、六维评估、成果7步法）。

## 九、萃取师五大能力（叶敬秋）

1. **回溯**（讲故事）：背景描述→进展冲突→细节描写→链接主题，还原故事情节曲线；
2. **捕捉**（抓关键）：从叙述中抓住真正重要的信息；
3. **归纳**（提炼）：把散点经验收敛成要点；
4. **升维**（抽象）：把具体经历升维为方法论主题；
5. **架构**（建模）：把要点组织成结构/模型。
> 与之配套的"萃取过程四步"（黄金提炼比喻）：选材 → 物理/化学加工（提炼）→ 成型，即"选择典型素材→加工提炼→封装成型"。

## 十、深挖要点 4 步法（通用追问骨架）

识别难点 → 挖掘做法 → 反思意图 → 探询可能（详见 `interview-question-bank.md` 与 `question-tree.md` 的八大方向）。
