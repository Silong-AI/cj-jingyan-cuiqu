# 组织级经验萃取与复制模式（Organization Mode）

适用：为企业/团队做组织级经验萃取与复制，如销售团队"把销冠经验变成团队能力"、岗位经验沉淀、打造标准化方法论。目标是**规模化复制**：让一批普通员工达到合格线，而不是只培养一两个高手。

## 核心理念

- **一群60分 > 三两个90分**：组织萃取的目的是整体产能提升，不是造明星。
- **80/20目标**：让80%的普通人掌握高手80%的能力、达到60分即可复用。
- **内萃外取**：向内萃取自家高手经验 + 向外借鉴行业标准方法论（如华为销售方法论），场景化融合。
- **训战结合**：萃取成果必须配套训练与实战，否则知识躺在文档里没有价值。

## 项目推进六步

### 第1步：立项与选场景
- 锁定关键业务场景（如"新客开发""大客户攻坚""续约留存"），场景要具体可考核。
- 明确业务收益：萃取后要提升什么指标（转化率/客单价/留存率）。

### 第2步：识别高手（三高模型）
筛选萃取对象，需同时满足：
- **绩效持续领先**：业绩持续领先，而非偶发爆发；
- **有具体案例**：讲得出有细节、有画面、有数据的成功案例；
- **有分享热情**：愿意分享、愿意带人（带教意愿直接影响复制效果）。

### 第3步：访谈/共创萃取（多轮）
- 对每位高手做 1-2 轮深度访谈，**按 `question-tree.md` 动态追问**（每轮给 2~5 个追问方向菜单，让高手自选方向深挖），话术从 `interview-question-bank.md` 取（还原场景→深挖做法→反思意图→探询边界）。
- 多位高手共创：用"团队经验提现法"打破三大黑洞——
  - **经验孤岛**：各自经验散落，无人整合；
  - **师徒困境**：只靠师徒传帮带，规模上不去；
  - **场景茧房**：经验只在单一场景有效，缺乏抽象。
- 用鱼骨图等工具做根因分析，找共性关键行为。
- 需要时取用具体战法：SBP敏捷萃取、三阶萃取、训战六步、GRAI/CSS复盘、一纸禅等见 `method-library.md`。

### 第4步：建模与封装（内萃外取+解构建构重构）
- **解构**：把高手行为拆成可描述的关键动作。
- **建构**：三角色协同（业务专家给场景、方法论专家给框架、萃取师做整合）。
- **重构**：形成"销售流程=导航图"，把经验转成标准动作/流程/话术。
- 关键行为筛选三维度：**重要度**（影响成败）× **频率**（反复出现）× **难度**（新手难掌握）→ 优先萃取三维度都高的行为。

### 第5步：验证（小步快跑）
- 萃取四原则：**有经验必萃取，有萃取必验证，验证后必固化，固化后必迭代**。
- 选试点团队试用标准方法论 → 对比业绩 → 反馈迭代。
- 科学验证：设定业务目标+行为指标+规则，用数据说话，不凭感觉。

### 第6步：训战落地与复制
- 建培训体系：**集中学习+微行动学习**（课堂学理论，工作中每周死磕一个关键行为）。
- 训战闭环六步**（启萃训演战盘）**：启动→萃取→训练→演练→实战→复盘（详见 `method-library.md`）。简化版闭环五环节：**训练 → 演练 → 实战 → 带教 → 复盘**。
- 黄埔带兵法七步：我说你听 → 我做你看 → 你做我看 → 你复盘我看 → 你做我看你复盘 → 你做我看你带人 → 你做我看你带人复盘。
- 技能养成三要素：**还原场景 + 高频练习 + 及时反馈**。
- 教学形式：TELL/SHOW/DO 三种设计 + 授课五环节"备启承展合"。
- **721 法则**：70% 实践 + 20% 交流 + 10% 课堂；警惕三大陷阱（只实践不萃取 / 学习流于形式无深度复盘 / 学习与实战脱节）。
- 晾晒机制：公开晒成果、晒行为，形成比学赶超氛围。
- 师徒复盘五问（带教时使用）。

## 销售场景专项（示例）

- 销售标准化方法论（参考华为）：**建标准 → 提能力 → 促增长**。
- 销售流程 = 导航图：把"开发-跟进-成交-交付-转介绍"拆成关卡与动作。
- 每周死磕一个行为：把提炼出的关键行为拆到每周训练计划。
- 演练剧本四部分：场景设定、角色扮演、标准话术、反馈点评。

## 组织模式要点
- 全程以"能否复制"为检验标准：高手能讲清楚、新手能照着做、结果可验证。
- 注意让高手参与验证与带教，避免"萃完就散"。
- 萃取成果需持续迭代，防止经验因市场变化而过期。

## 组织经验萃取核心要素（萃取师为中心）
- **获取侧**：萃取主题（从哪萃）、经验源头（向谁萃）、萃取方式（怎么萃：访谈/共创/复盘）。
- **传播侧**：传播载体（成果物）、传播方式（怎么传）、推广复制（怎么用）。
- **挖-采-用三圆模型**：挖＝锁定对象、核心任务、关键行为、分析挑战、聚焦问题；采＝叙述过程、提炼经验、深挖难点、显化行为；用＝典型案例、微课应用、课程开发、标准建立。

## 萃取主题如何选（叶敬秋）
- **三途径**：①从业务痛点着手（全员常卡壳/反复出错/效率低的重点业务）；②从课程内容选取；③从优秀人物/高光事件升维。
- **从业务场景到痛点挖掘漏斗**：对象（避免错位）→工作任务（助力回溯）→高价值应用场景（缩小切口）→萃取主题（锚定指向）。
- **萃取主题万能公式**：精准人物身份 + 如何 + 核心任务场景（任务关键环节）+ 解决核心痛点（主观→补齐短板提升能力；客观→突破限制搞定外部约束）。
- **高光事件升维五维评估**：业务结果（有无数据成果）、难点逆境（是否逆势完成）、独有方法（有无差异打法）、公司价值（是否贴合战略）、可复制性（普通人能否快速学会）。

## 复盘+萃取战法（必赢之战模式，陈晓燕）
- **底层逻辑**：大卫·库伯经验学习圈（积极实践→产生经验→反思性观察→抽象概念化）。金句："不盘不萃不会""萃取之前必复盘"；复盘是找到真牛人牛事牛招及萃取点的捷径。
- **结构化四步复盘法**：回顾目标→评估策略→反思过程→总结规律；反思过程四原则：按顺序、是事实、需完整、无观点。
- **复盘+萃取时机矩阵（边战边萃·战萃一体·战传合一）**：项目初起→盘目标/战前研究标杆巧做迁移；步及正轨→盘策略/验证；项目至中→盘问题/战中经验涌现、英雄借出、快速复制；项目中后→盘经验/验证；项目结项→盘规律/战后固化打法迭代系统。
- **复盘画布四大模块**：回顾目标（战略解码）、评估策略（战术支撑）、反思过程（战斗反思）、总结规律（战备系统）。深挖诊断：目标不清用"上堆战略、下切承诺、寻因结构、问果指标"；亮点用"拍照式学习→解剖式追问→基因式重构"；不足用"反思行为/假设/认知/系统"。
- **复盘漏斗选萃取主题**：战场→任务→战斗过程→亮点/难点→萃取主题描述；用三维筛选矩阵（高难度×高价值、重要×紧急、覆盖广×高频）优选。

## 专家经验共创画布（多人共创工具）
- 模块：共创主题 → 典型事件（案例）名称 → 聚焦关键点（5-7个问题） → 事件解决过程（做法/具体行动、原因/理由、细节描述/例证） → 结构化提炼（步骤/要点、难点/对策）。
- 流程：每位专家把具体做法写在贴纸上→主持人组织去伪存真→按类别归栏→讨论理由和细节→用动宾结构提炼技能→分析难点对策→总结步骤逻辑关系图（模型）。

## 萃取方法选型四象限（经验萃取VS解决方案）
- 通用技能+有标杆→内部采集；专业技能+有标杆→专家访谈；通用技能+无标杆→外部采集；专业技能+无标杆→专家共创。

## AI+训战式岗位经验萃取五步（叶敬秋/周珊）
- 定（四定，1周）→萃（经验萃取赋能2天+多元成果开发2天，2周）→训（训练带教+情景演练，2周）→战（试点实战+一对一反馈辅导，2-3周）→盘（CSS复盘+迭代更新，1-2月）。
- 经验萃取融入业务全流程四场景：谋布局（战略决策后）、解难题（卡脖子难题中）、提成果（成果迭代时）、固沉淀（项目攻坚后）。

## 销售场景专项补充（曾子亮/华为）
- 销售组织进化路线：团伙制→首席制→诸侯制→集体制（规模化增长的核心是从"团伙制"进化为"集体制"）。
- 业绩规模化增长公式：业绩规模化增长 = 每个人卖的更多 × 能卖的人更多。
- 内萃外取选择三考量：内部有没有优秀经验、能不能承接当前业务要求、能不能承接未来战略要求。
